Herdr 是一个终端原生的 Agent 运行时和多路复用器。它为整个"牛群"提供持久的终端工作区，具备面板、标签页、鼠标控制、状态感知能力，以及 Agent 自身可以调用的 API。

```bash
curl -fsSL https://herdr.dev/install.sh | sh
herdr
```
