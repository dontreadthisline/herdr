title: 持久化与远程访问
description: 从 Herdr 分离、稍后重新接入、使用命名会话以及通过 SSH 连接。
---

Herdr 在后台服务端中保持面板运行。你的终端客户端可以分离并稍后重新连接。

关于本地、SSH 和 `herdr --remote` 工作流，请参阅[工作方式](/zh-cn/docs/how-to-work/)。

## 分离和重新接入

启动 Herdr：

```bash
herdr
```

使用 `ctrl+b q` 分离客户端。

你的面板和 Agent 会继续运行。通过再次运行 Herdr 重新接入：

```bash
herdr
```

如果你希望结束会话并停止其面板，停止默认服务端：

```bash
herdr server stop
```

当 Herdr 在完全服务端停止后再次启动时，它会恢复保存的会话形态。关于分离、服务端重启、屏幕历史回放、原生 Agent 会话恢复和实时交接中哪些内容会存活，请参阅[会话状态与恢复](/zh-cn/docs/session-state/)。

## 命名会话

当你需要独立的 Herdr 服务端时，使用命名会话。

```bash
herdr session list
herdr session attach work
herdr session attach side-project
herdr session stop work
herdr session delete side-project
```

命名会话拥有自己的面板、标签页、工作区、socket 和运行时状态。它仍然共享相同的全局配置文件。

对脚本使用 `--json`：

```bash
herdr session list --json
herdr session stop work --json
herdr session delete side-project --json
```

## 通过 SSH 远程接入

在服务器上运行 Herdr，从任意 SSH 客户端接入：

```bash
ssh you@server
herdr
```

在此模式下，你的 shell 是远程的，Herdr 运行在远程主机上，面板在你分离后继续在该主机上运行。

你还可以从本地机器通过 SSH 接入：

```bash
herdr --remote workbox
herdr --remote ssh://you@server:2222
```

在此模式下，你的本地 Herdr 作为瘦客户端。它通过 SSH 连接，启动或接入远程 Herdr 服务端，并将 UI 流式传输回你的本地终端。因为客户端在本地运行，Herdr 可以将本地桌面功能（如图片剪贴板粘贴）桥接到远程会话，方法是将图片复制到远程临时文件并粘贴该路径。

默认情况下，`herdr --remote` 使用你本地的 Herdr 键位绑定进行连接。这意味着即使远程服务端有不同的配置，你也能保持本地肌肉记忆。本地键位绑定是接入时的快照；编辑本地键位后需要分离并重新接入。当你希望使用远程服务端配置时，使用 `--remote-keybindings server`。本地的自定义命令键位绑定不会被发送，因为这些命令将在远程主机上运行。

对于重复连接的目标，使用你的 SSH 配置：

```text
Host workbox
  HostName server.example.com
  User you
  Port 2222
```

然后使用以下命令接入：

```bash
herdr --remote workbox
```

远程接入支持 x86_64 和 aarch64 上的 Linux 和 macOS 主机。Herdr 检查远程平台，优先使用远程 `PATH` 中已有的匹配 `herdr`，然后检查 `~/.local/bin/herdr`。如果不存在匹配的二进制文件，交互式运行会提示安装一个到 `~/.local/bin/herdr`；非交互式运行会失败而不是修改主机。如果 `~/.local/bin` 不在远程 `PATH` 中，Herdr 会在安装后警告。

默认情况下，远程接入使用正常的重启/停止流程来替换或重启运行中的远程服务端。要对支持的运行中远程服务端启用实验性的实时交接，传入 `--handoff`：

```bash
herdr --remote workbox --handoff
```

如果你先 SSH 进入服务器然后在那里运行 `herdr`，Herdr 完全在服务端运行。该模式有用且简单，但除了普通终端文本粘贴外，无法访问你的本地桌面剪贴板。

当本地和远程平台匹配时，Herdr 可以复制当前本地二进制用于直接安装。对于 Homebrew 和 Nix 安装，或平台不同时，它从 `https://herdr.dev/latest.json` 下载匹配的当前客户端版本的发行版资产。

对于本地构建或自定义二进制文件，在运行远程接入之前设置 `HERDR_REMOTE_BINARY` 为本地文件路径。

```bash
HERDR_REMOTE_BINARY=target/release/herdr herdr --remote workbox
```

## 远程命名会话

使用 `--session` 配合 `--remote` 来接入远程主机上的命名会话：

```bash
herdr --remote workbox --session agents
```

## 直接终端接入

完整的 Herdr 接入打开整个工作区 UI。直接接入在你当前的终端中打开一个服务端拥有的终端。

按 Agent 目标接入：

```bash
herdr agent attach reviewer
```

按终端 ID 接入：

```bash
herdr terminal attach term_abc123
```

直接接入先流式传输当前渲染的终端状态，然后是实时的 ANSI 帧。输入直接发送到该终端。

使用 `ctrl+b q` 分离。发送字面量 `ctrl+b` 使用 `ctrl+b ctrl+b`。

一个终端同时只能有一个可写的直接接入客户端拥有输入和调整大小的权限。使用 `--takeover` 替换现有的拥有者：

```bash
herdr terminal attach term_abc123 --takeover
```

## 单进程模式

使用 `--no-session` 在没有后台服务端/客户端分离的情况下运行 Herdr：

```bash
herdr --no-session
```

这主要用于调试或兼容性场景。默认的持久化会话模式是正常路径。
