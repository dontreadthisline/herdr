Herdr 无需配置文件即可工作。当你需要自定义按键、主题、侧边栏设置、通知或高级行为时，再添加配置。

## 配置文件

Herdr 从以下位置读取配置：

```text
~/.config/herdr/config.toml
```

打印完整的默认配置：

```bash
herdr --default-config
```

如果你想要一个完整的起点，将其保存为配置：

```bash
herdr --default-config > ~/.config/herdr/config.toml
```

如果配置值无效，Herdr 会回退到安全默认值并显示启动警告。

当 `onboarding` 缺失或为 true 时，Herdr 显示首次运行设置。从 onboarding 继续会写入 `onboarding = false` 并在集成标签页上打开设置。在设置完成后设置它以跳过该流程。

```toml
onboarding = false
```

## 重载配置

编辑 `config.toml` 后重载运行中的服务端：

```bash
herdr server reload-config
```

你也可以在 Herdr 中打开全局菜单并选择 `reload config`。

重载会应用大多数 UI 设置，而无需重启面板。仅启动时生效的设置仍需要重启。

## 终端默认值

设置 Herdr 为新创建的交互式面板使用的可执行文件：

```toml
[terminal]
default_shell = "nu"
```

当未设置或为空时，Herdr 使用 `$SHELL`，然后是 `/bin/sh`。这是一个可执行文件名或路径，而不是 shell 命令行。现有面板保持其当前 shell，直到被重新创建。命令面板仍通过 `/bin/sh -c` 运行；分离的自定义命令键位绑定使用 Herdr 现有的 `/bin/sh -lc` 路径。

设置 Herdr 如何启动新创建的交互式面板 shell：

```toml
[terminal]
shell_mode = "auto"
```

`shell_mode = "auto"` 在 macOS 上启动登录 shell，以便仅登录可用的 PATH 设置（如 `/usr/libexec/path_helper` 和 Homebrew shell 初始化）在新面板中运行。在其他平台上，它保持现有的非登录 shell 行为。使用 `"login"` 强制登录 shell 启动，或 `"non_login"` 选择退出。命令面板、分离的自定义命令键位绑定和显式 argv 启动保持其现有的命令执行路径。

设置新面板、标签页和工作区的工作目录策略：

```toml
[terminal]
new_cwd = "follow"
```

`new_cwd = "follow"` 保持默认行为，继承源面板或工作区的目录。使用 `"home"` 始终在 `$HOME` 中启动，`"current"` 使用 Herdr 的进程目录，或固定路径如 `"~/Projects"`。来自 CLI 或 Socket API 的显式 `--cwd` 值仍然具有更高优先级。

## 工作树

设置 Herdr 用于从侧边栏创建的 Git 工作树检出的根目录：

```toml
[worktrees]
directory = "~/.herdr/worktrees"
```

Herdr 在 `<directory>/<repo>/<branch-slug>` 下创建检出。对于兄弟风格的检出，将此设置为诸如 `~/Projects/herdr-worktrees` 的目录。相对值在应用配置时被解析为绝对路径。

工作树操作在 Git 工作区行上可用。`New worktree` 创建分支和检出，将其打开为一个新的 Herdr 工作区，并分组在源工作区下。`Open worktree...` 列出该仓库现有的 Git 工作树检出；选择已打开的检出会聚焦它，选择已关闭的检出在同一组中打开它。

分组的工作树仍然表现得像普通的 Herdr 工作区：它们可以被聚焦、重命名、关闭，并包含自己的标签页和面板。父行是原始工作区。关闭父行会关闭整个 Herdr 组，但不会删除检出文件夹或分支。

删除工作树检出是显式的。使用分组子工作区上的 `Delete worktree checkout...` 来运行 `git worktree remove`。Herdr 首先要求 Git 安全删除。如果 Git 因为检出有修改或未跟踪的文件而拒绝，Herdr 在执行强制删除前再次询问。分支不会被删除。

## 键位绑定

Herdr 有类似 tmux 的前缀模式。默认前缀是 `ctrl+b`。键位绑定字符串是显式的：`prefix+n` 表示按下配置的前缀键然后按 `n`；`ctrl+alt+n` 是直接的终端模式快捷键。

一个简短的键位覆盖示例：

```toml
[keys]
prefix = "ctrl+b"
goto = "prefix+g"
new_tab = "prefix+c"
next_tab = "prefix+n"
previous_tab = "prefix+p"
focus_pane_left = "prefix+h"
navigate_workspace_down = "j"
navigate_pane_down = "ctrl+j"
split_horizontal = "prefix+minus"
```

默认键位映射以前缀优先，避免直接的快捷键抢夺 shell、编辑器、tmux 或终端应用的输入。常用默认值包括：

```toml
[keys]
detach = "prefix+q"
workspace_picker = "prefix+w"
goto = "prefix+g"
new_workspace = "prefix+shift+n"
new_worktree = "prefix+shift+g"
rename_workspace = "prefix+shift+w"
close_workspace = "prefix+shift+d"
navigate_workspace_up = "up"
navigate_workspace_down = "down"
navigate_pane_left = "h"
navigate_pane_down = "j"
navigate_pane_up = "k"
navigate_pane_right = "l"
new_tab = "prefix+c"
previous_tab = "prefix+p"
next_tab = "prefix+n"
switch_tab = "prefix+1..9"
rename_tab = "prefix+shift+t"
close_tab = "prefix+shift+x"
copy_mode = "prefix+["
focus_pane_left = "prefix+h"
focus_pane_down = "prefix+j"
focus_pane_up = "prefix+k"
focus_pane_right = "prefix+l"
cycle_pane_next = "prefix+tab"
cycle_pane_previous = "prefix+shift+tab"
last_pane = ""
split_vertical = "prefix+v"
split_horizontal = "prefix+minus"
close_pane = "prefix+x"
zoom = "prefix+z"
resize_mode = "prefix+r"
toggle_sidebar = "prefix+b"
```

可选操作默认未设置。使用 `prefix+` 绑定为前缀模式行为，或当你确实想要直接快捷键时使用显式的修饰键组合：

```toml
[keys]
previous_workspace = "prefix+shift+left"
next_workspace = "prefix+shift+right"
last_pane = "prefix+tab"
open_worktree = "prefix+shift+o"
remove_worktree = "prefix+alt+d"
next_tab = ["prefix+n", "ctrl+alt+]"]
```

`last_pane` 跨工作区和标签页切换回上次聚焦的面板。默认未设置，因为 tmux 风格的面板绑定 `prefix+l` 已用于面板右聚焦。

键字符串接受普通键、修饰键组合（如 `ctrl+a`、`shift+n`、`alt+1`、`cmd+k`），以及特殊键（如 `enter`、`tab`、`esc`、`left`、`right`、`up`、`down`）。命名标点符号（如 `minus`、`comma`、`ampersand`、`plus`、`backtick`）也可以接受。普通可直接打印的键（如 `n`）是不安全的，因为它们会拦截输入；除非你有意想要直接绑定，否则使用 `prefix+n`。`navigate_workspace_*` 和 `navigate_pane_*` 字段仅限导航模式，可以使用 `j` 或 `k` 等普通键；它们不得使用 `prefix+`、`esc`、`enter`、`tab`、`shift+tab`、`left`、`right` 或未修饰的 `1` 到 `9`。左箭头和右箭头是面板左右导航的永久别名。这些导航模式快捷键独立于通用操作绑定（如 `focus_pane_down = "prefix+j"`）；当两者使用相同键时，导航模式打开的期间导航模式快捷键优先。Alt、Cmd/Super 以及带修饰符的标点符号取决于你的终端和 tmux 设置。

如果你有旧的自定义键位绑定并想要新的默认值，运行 `herdr config reset-keys`。Herdr 备份 `config.toml`，移除 `[keys]` 和 `[[keys.command]]`，并在重启或 `herdr server reload-config` 后使用内置的 v2 默认值。

## 索引跳转

索引键位绑定在普通键位绑定字段中使用 `1..9`：

```toml
[keys]
switch_tab = "prefix+1..9"
switch_workspace = "prefix+shift+1..9"
focus_agent = "prefix+alt+1..9"
```

旧版 `[keys.indexed]` 表仍为兼容而解析，但新配置应优先使用显式的操作字段。

## 自定义命令键位绑定

自定义命令使用相同的键位绑定语法。

```toml
[[keys.command]]
key = "prefix+alt+g"
type = "pane"
command = "lazygit"
description = "运行 lazygit"
```

`type = "pane"` 打开一个临时面板，命令退出时关闭。

`type = "shell"` 在后台分离运行。

可以提供可选的 `description`。指定后，该描述会显示在键位帮助面板中（通过 `prefix+?` 打开），替代默认的 `'custom command'` 标签。

自定义命令在可用时接收 `HERDR_SOCKET_PATH`、`HERDR_BIN_PATH`、`HERDR_ACTIVE_WORKSPACE_ID`、`HERDR_ACTIVE_TAB_ID`、`HERDR_ACTIVE_PANE_ID` 和 `HERDR_ACTIVE_PANE_CWD` 环境变量。当 Herdr 可以检测到时，Shell 命令从聚焦面板的工作目录运行。

## 主题

选择一个内置主题：

```toml
[theme]
name = "catppuccin"
```

内置主题：

`catppuccin`、`catppuccin-latte`、`terminal`、`tokyo-night`、`tokyo-night-day`、`dracula`、`nord`、`gruvbox`、`gruvbox-light`、`one-dark`、`one-light`、`solarized`、`solarized-light`、`kanagawa`、`kanagawa-lotus`、`rose-pine`、`rose-pine-dawn`、`vesper`。

当你想让 Herdr UI 颜色跟随主机终端的 ANSI 调色板时，使用 `terminal`。

你可以覆盖个别颜色：

```toml
[theme.custom]
panel_bg = "reset"
accent = "#a6e3a1"
green = "#a6e3a1"
blue = "#89b4fa"
red = "#f38ba8"
yellow = "#f9e2af"
```

颜色值接受十六进制、命名颜色、`rgb(r,g,b)`，或重置别名（如 `reset`、`default`、`none`、`transparent`）。

## UI 和侧边栏

侧边栏是 Herdr 的主仪表盘。它显示工作区、标签页、面板和 Agent 状态。

常用选项：

```toml
[ui]
sidebar_width = 32
sidebar_min_width = 18
sidebar_max_width = 36
mobile_width_threshold = 64
mouse_capture = true
redraw_on_focus_gained = true
mouse_scroll_lines = 3
confirm_close = true
prompt_new_tab_name = true
show_agent_labels_on_pane_borders = false
agent_panel_scope = "all"
accent = "cyan"
```

`sidebar_min_width` 和 `sidebar_max_width` 控制展开的侧边栏的调整范围（以列为单位）。默认值分别为 18 和 36。

`mobile_width_threshold` 控制终端宽度，当小于等于该值时 Herdr 使用移动端单列布局。默认值为 64 列；对于可折叠设备、平板或宽手机终端可以增大。

`agent_panel_scope` 可以是 `all` 或 `current`。如果你只想让 Agent 面板显示当前工作区中的 Agent，使用 `current`。

`confirm_close` 控制关闭工作区时是否需要确认。`prompt_new_tab_name` 控制新建标签页时是否先要求提供标签名。

如果你希望终端处理普通点击（如命令点击 URL），设置 `mouse_capture = false`。当鼠标捕获启用时，Ctrl-点击在终端将该修改后的点击发送给 Herdr 时打开面板链接；使用 Linux 上的 Shift-Ctrl-点击或 macOS 上的 Shift-Cmd-点击作为终端原生绕过路径。

设置 `redraw_on_focus_gained = false` 以避免在切换回 Herdr 时可见的全屏刷新。默认值为 `true`，因为全屏重绘可以从罕见的陈旧或脏主机终端表面恢复。

设置 `mouse_scroll_lines` 以更改每个鼠标滚轮刻度的面板回滚行数。默认值为 3。请求鼠标报告的面板应用仍直接接收滚轮事件。

如果你希望在未设置手动面板标签时在分割面板边框上显示检测到的 Agent 标签，设置 `show_agent_labels_on_pane_borders = true`。

## 通知

Herdr 可以在 Agent 完成或需要输入时显示弹出通知。

```toml
[ui.toast]
delivery = "off"
```

`delivery = "off"` 禁用弹出通知。这是默认值。

`delivery = "herdr"` 在 Herdr UI 内显示右上角的 toast 通知。点击 toast 或绑定 `keys.open_notification_target` 来聚焦目标工作区、标签页和面板。

`delivery = "terminal"` 要求外部终端显示桌面通知。Herdr 为 Ghostty、iTerm2、Kitty 和 WezTerm 发送终端通知逃逸序列。这在通过 SSH 使用时很有用，因为本地终端拥有通知。

`delivery = "system"` 直接向本地操作系统请求通知。在 macOS 上，Herdr 优先使用 `terminal-notifier`（可用时），然后回退到 `/usr/bin/osascript`。`terminal-notifier` 可以在你点击通知时激活托管终端。在 Linux 上，Herdr 使用 `notify-send`，需要 `DISPLAY` 或 `WAYLAND_DISPLAY`。

弹出通知用于后台关注。Herdr 对活跃标签页抑制弹出通知。

## 声音

声音通知默认启用，由本地 Herdr 客户端播放。

```toml
[ui.sound]
enabled = true
```

Herdr 在 Agent 完成时播放完成声音，在 Agent 需要输入时播放提醒声音。在共享机器或远程服务器上，除非你明确需要音频，否则设置 `enabled = false`。

在 macOS 上，Herdr 使用 `afplay`。在 Linux 上，Herdr 按顺序尝试支持 mp3 的播放器：`paplay`、`pw-play`、`ffplay`、`mpg123`，然后是 `mpv`。如果没有可用的播放器，声音播放被跳过，Herdr 记录一条警告。

自定义声音必须是 mp3 文件。相对路径从配置文件所在目录解析。

```toml
[ui.sound]
path = "sounds/notification.mp3"
done_path = "sounds/done.mp3"
request_path = "sounds/request.mp3"
```

`path` 为所有声音通知设置一个声音。`done_path` 和 `request_path` 仅覆盖完成和需要输入的声音。

每个 Agent 的声音覆盖接受 `default`、`on` 或 `off`。Droid 默认静音。

```toml
[ui.sound.agents]
droid = "off"
claude = "on"
```

## 滚动缓冲区

设置新创建面板的滚动缓冲区大小：

```toml
[advanced]
scrollback_limit_bytes = 10485760
```

现有面板保持其当前缓冲区，直到被重新创建。

## 面板屏幕历史

默认情况下，完全会话重启会恢复工作区、标签页、面板、工作目录、布局和焦点，但不保存面板内容。

面板屏幕历史默认关闭。面板输出可能包含密钥、令牌、提示和命令输出，因此仅在你希望 Herdr 在完全服务端重启时保存最近的面板内容时才启用：

```toml
[experimental]
pane_history = true
```

你也可以从 设置 > 实验 > 面板屏幕历史 切换。

启用后，Herdr 将保存的面板历史存储在 `session-history.json` 中（与 `session.json` 并列）。

关于面板屏幕历史与实时持久化、快照恢复、原生 Agent 会话恢复和实时交接的区别，请参阅[会话状态与恢复](/zh-cn/docs/session-state/)。

## 嵌套启动

Herdr 通常保护你不会在 Herdr 内部启动 Herdr。

```toml
[experimental]
allow_nested = false
```

仅在测试时启用嵌套启动。

## Kitty 图形

Kitty 图形支持是实验性的。

```toml
[experimental]
kitty_graphics = false
```

保持关闭，除非你正在测试终端图像行为。

## Agent 会话恢复

Herdr 可以在 Herdr 服务端重启后，在原生对话会话中重启支持的 Agent 面板。

```toml
[session]
resume_agents_on_restore = false
```

启用后，Herdr 仅恢复通过官方 Herdr 集成上报了原生会话引用的面板。支持的恢复目标是 Claude Code、Codex、Pi、Hermes Agent 和 OpenCode。不受支持、缺失、无效、重复或过期的会话引用会恢复为保存面板目录中的普通 shell。

会话引用存储在本地 Herdr 会话快照中。它们不会在普通的面板、Agent、状态或事件输出中显示。

关于原生 Agent 会话恢复与面板屏幕历史和实时交接的区别，请参阅[会话状态与恢复](/zh-cn/docs/session-state/)。

## IME 光标跟踪

当聚焦的面板隐藏其光标并绘制自己的光标时 -- 这在 Claude Code、pi 和 codex 等 AI Agent TUI 中很常见 -- macOS 原生输入法会停止跟踪候选窗口位置，因为外部终端停止报告光标。

设置 `reveal_hidden_cursor_for_cjk_ime = true` 以将聚焦面板的光标锚点暴露给外部终端，无论面板的 `?25l` 请求如何：

```toml
[experimental]
reveal_hidden_cursor_for_cjk_ime = false
cjk_ime_agents = []
cjk_ime_cursor_shape = "steady_block"
```

启用后，光标在聚焦面板报告的位置保持可见。如果面板报告无光标位置，锚点回退到面板左上角，以确保始终有稳定的 IME 提示可用。

`cjk_ime_agents` 是一个可选的白名单。为空时，显示适用于任何聚焦的面板。非空时，仅当聚焦面板的检测 Agent 匹配列表中的名称之一时才适用 -- 这对于仅对绘制自己光标的 AI Agent TUI 启用光标显示而保持普通 shell 不变很有用。接受的名称：`pi`、`claude`、`codex`、`gemini`、`cursor`、`agy`、`cline`、`opencode`、`copilot`、`kimi`、`kiro`、`droid`、`amp`、`grok`、`hermes`、`qodercli`、`qoder`。未知名称被忽略；如果列表中不包含有效名称，则不会应用。

`cjk_ime_cursor_shape` 控制为 IME 锚点渲染的 DECSCUSR 形状。接受的值：`block`、`steady_block`（默认）、`underline`、`steady_underline`、`bar`、`steady_bar`。

通过现有的 `[experimental]` 块热重载。

启用时的权衡：对于隐藏光标而不绘制替代光标的应用（vim 普通模式等），外部终端会显示一个额外的硬件光标。将光标显示与 `cjk_ime_agents` 配对以限定到特定的 TUI。

## 环境变量

| 变量 | 用途 |
| --- | --- |
| `HERDR_CONFIG_PATH` | 覆盖配置文件路径。 |
| `HERDR_SESSION` | 为 CLI 命令选择命名会话。 |
| `HERDR_SOCKET_PATH` | 底层 socket 路径覆盖。 |
| `HERDR_LOG` | 设置日志过滤，例如 `HERDR_LOG=herdr=debug`。 |
| `HERDR_DISABLE_SOUND` | 即使 `[ui.sound] enabled = true` 也禁用声音播放。 |

## 日志

在诊断启动警告、集成状态或 Socket API 行为时，日志很有用。

常见日志文件：

```text
~/.config/herdr/herdr.log
~/.config/herdr/herdr-client.log
~/.config/herdr/herdr-server.log
```

日志自动轮替。在报告问题时包含当前日志和已轮替的文件。
