---
title: 核心概念
description: 理解 Herdr 的工作区、标签页、面板、Agent、会话和模式。
---

Herdr 是一个终端工作区管理器。它保持真实的终端进程运行，并在其之上添加结构。

## 工作区

工作区是顶层的项目容器。为每个仓库、任务或调研使用一个工作区。

工作区拥有标签页和面板。其侧边栏状态由内部的 Agent 汇总而来，因此你可以看到哪个项目需要注意。

## 标签页

标签页是工作区内的布局。使用标签页来分离不同的视图，如 `agents`、`logs`、`server` 或 `review`。

标签页可以从 CLI 和 Socket API 进行寻址。

## 面板

面板是一个真实的终端。Herdr 渲染终端输出，将输入发回进程，并在客户端分离后保持面板持久存在。

面板可以向右或向下分割。可以手动重命名，从 CLI 读取，发送输入以及关闭。

## Agent

Agent 是 Herdr 在面板内识别到的进程。Herdr 通过前台进程、屏幕启发式和可选的集成来检测 Agent。

Agent 状态包括：

| 状态 | 含义 |
| --- | --- |
| `blocked` | Agent 需要输入、批准或决策。 |
| `working` | Agent 正在活跃运行。 |
| `done` | Agent 已完成且你尚未查看。 |
| `idle` | Agent 已完成或等待中且已被查看。 |
| `unknown` | Herdr 无法自信地分类该状态。 |

## 会话

会话是一个持久的 Herdr 服务端命名空间。默认的 `herdr` 命令会附加到默认会话。

命名会话是独立的运行时命名空间：

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

优先使用工作区。当你需要完全独立的面板、socket 和持久化运行时状态时，再使用命名会话。

## 客户端与服务端

默认情况下，Herdr 以一个后台服务端加一个或多个附加客户端的方式运行。

服务端拥有面板和进程状态。客户端是附加到该服务端的终端 UI。

使用 `ctrl+b q` 分离客户端。服务端和 Agent 会继续运行。

如果你希望结束会话并停止其面板，停止服务端：

```bash
herdr server stop
```

## 模式

Herdr 有终端模式、前缀模式和导航模式。

终端模式将键发送到聚焦的面板。前缀模式在前缀键之后等待一个 Herdr 操作。导航模式是持久的工作区导航界面。

按下前缀键（默认为 `ctrl+b`），然后按一个操作键，如 `c` 新建标签页或 `w` 进行工作区导航。

## 鼠标 UI

Herdr 原生支持鼠标。你可以点击面板、标签页、工作区和 Agent。可以拖动分割边界、选择文本以及使用右键菜单。

如果你更偏好纯键盘控制，或希望 Herdr 停止捕获鼠标输入，请禁用鼠标捕获：

```toml
[ui]
mouse_capture = false
```
